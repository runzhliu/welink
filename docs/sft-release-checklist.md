## 正式发布前必须补齐

- [ ] Mac 原生 arm64 Python 3.12，按 lock 安装成功，记录 macOS、芯片、统一内存和所有依赖版本。
- [ ] CUDA Linux x86_64 按 lock 安装成功，记录 GPU、驱动、CUDA、显存与所有依赖版本。
- [ ] 两端分别选择一个固定 commit 的真实小模型，记录许可、基础权重内容 hash、tokenizer / template hash、原始数据版本及编译参数。
- [ ] 两端真实 tokenizer / collator 的最终 assistant labels 与 padding 遮罩通过；不能只验证布尔参数或替身 tokenizer。
- [ ] 两端通过两次真实 optimizer updates 预检，再完成一次短训，确认实际训练 / 验证 loss、步数、内存和产物校验和。
- [ ] Mac 权重继续明确重建优化器；GPU 完整状态恢复验证 optimizer / scheduler / RNG / 数据进度连续性。
- [ ] 刷新、关闭浏览器、控制端重启、worker 重启、上传中断与睡眠 / 断网恢复，不重复启动或复活终态。
- [ ] 两端停止训练后实际保存退出；注入 OOM、磁盘不足、NaN、半文件、过期 fence 和撤销 worker，核对错误与有效恢复点。
- [ ] 基础 / 微调模型用同一冻结测试版本完成 loss 和固定问题生成；人工盲测投票前看不到名称 / 参考答案，投票后揭晓。
- [ ] 两端推理服务通过健康检查与真实流式 smoke test；从 WeLink 首页等现有 profile 入口试聊、设默认并回滚。
- [ ] 390px 手机与桌面、深浅色、键盘 / 屏幕阅读器视觉验收，检查浮层、长模型名、长中文日志和录屏隐私模式。
- [ ] 打包后的 Mac App 完成 worker 安装说明与实际连接验证；Docker 通过可信 HTTPS 代理完成远程配对 / 传输。

Mac MLX 硬件训练、CUDA 恢复与故障注入、移动端和打包应用等项目仍待验收，不应将已发布或单次 L20 冒烟理解为完成硬件验收。

## 当前边界与设计收敛

- 首版只训练本人私聊风格，保留 legacy LoRA ZIP 导出；不包含群人格、第三方人物、DPO、全参数或多卡训练。
- 环境由独立 worker 的隔离 Python 环境启用，工作台提供固定依赖安装 / 配对命令；不从网页执行任意 shell，也不自动安装全局 Python 或驱动。
- 模型需要用户指定精确 Hugging Face revision，通过真实预检后才进入训练；当前没有经过硬件验收的预置模型白名单。
- JSONL 导入通过数据草稿接口完成，单文件最大 32 MB / 20,000 条。worker 的权重传输支持分块续传；浏览器的 JSONL 导入为有界整文件提交。
- 指标与事件支持持久化分页 / SSE；页面使用可恢复的 HTTP 增量轮询，关闭页面不影响任务。
- GGUF / Ollama 转换未纳入首版；基础 MLX / Transformers 推理路径保留，UI 不承诺任意格式可互换。
- 失败文件清理只覆盖控制端；worker 的 Hugging Face 缓存由机器本地管理。成功模型、冻结版本和被后续任务引用的文件不自动清理。

## 硬件验收记录模板

每个环境记录：测试日期、提交 SHA、账号匿名 ID、数据版本 SHA、模型 ID / commit / 内容 hash、执行器及完整依赖版本、设备、预检 job、训练 job、实际 steps / loss / 内存、停止与恢复 job、评测样本数、部署 / 流式调用记录、默认与回滚结果、失败注入结果、执行人。记录中不包含原始聊天、密钥或 SSH 凭据。
