## 当前边界与设计收敛

- 首版只训练本人私聊风格，保留 legacy LoRA ZIP 导出；不包含群人格、第三方人物、DPO、全参数或多卡训练。
- 环境由独立 worker 的隔离 Python 环境启用，工作台提供固定依赖安装 / 配对命令；不从网页执行任意 shell，也不自动安装全局 Python 或驱动。
- 模型需要用户指定精确 Hugging Face revision，通过真实预检后才进入训练；当前没有经过硬件验收的预置模型白名单。
- JSONL 导入通过数据草稿接口完成，单文件最大 32 MB / 20,000 条。worker 的权重传输支持分块续传；浏览器的 JSONL 导入为有界整文件提交。
- 指标与事件支持持久化分页 / SSE；页面使用可恢复的 HTTP 增量轮询，关闭页面不影响任务。
- GGUF / Ollama 转换未纳入首版；基础 MLX / Transformers 推理路径保留，UI 不承诺任意格式可互换。
- 失败文件清理只覆盖控制端；worker 的 Hugging Face 缓存由机器本地管理。成功模型、冻结版本和被后续任务引用的文件不自动清理。
